Dijkstra's Shortest Path Algorithm

The core of our navigation system uses Dijkstra's algorithm, a fundamental graph algorithm that finds the shortest path between nodes in a weighted graph. The supermarket floor plan is represented as a graph where intersections and product locations are nodes, and walkable paths are edges with distances as weights.

This ensures you always get the most efficient route, saving time and effort while shopping.
